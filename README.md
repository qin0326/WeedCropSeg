# Wavelet-Enhanced Dual-Modal Network for Weed-Crop Segmentation under High Geometric Similarity



## Introduction

This repository accompanies our work on a **Wavelet-Enhanced Dual-Modal Network for Weed-Crop Segmentation under High Geometric Similarity**. The framework integrates RGB and near-infrared (NIR) imagery and incorporates high-frequency-enhanced downsampling (HFED), high-frequency-refined upsampling (HFRU), and coordinate-guided alignment (CGA) to enhance feature representation and fusion.
